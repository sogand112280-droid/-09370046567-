همراه مهر - قالب استاتیک وب‌سایت فارسی

فایل‌ها:
- index.html
- style.css
- script.js

انتشار در GitHub Pages:
1) یک مخزن جدید در GitHub بسازید.
2) این سه فایل را مستقیماً در ریشه مخزن بارگذاری کنید (نه داخل پوشه).
3) از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
4) Branch را روی main و Folder را روی /(root) قرار دهید و Save بزنید.
5) پس از چند دقیقه، نشانی سایت در همان بخش نمایش داده می‌شود.

پیش از انتشار:
- نام و راه ارتباطی واقعی را جایگزین کنید.
- فرم فعلی نمایشی است و اطلاعات را ارسال یا ذخیره نمی‌کند.
- این قالب ادعای مجوز، وابستگی دولتی یا تضمین حقوقی ندارد. ارائه خدمات واقعی باید با رعایت قوانین محل فعالیت و مجوزهای لازم باشد.
- از جمع‌آوری مدارک هویتی، اطلاعات بانکی یا داده‌های حساس در فرم عمومی خودداری کنید.
